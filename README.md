# Intel Physiotherapy Website

A professional static website designed for a physiotherapy, rehabilitation, fitness, and wellness service provider.

## Project Overview

This project is a modern, responsive, and lightweight website built to present healthcare and wellness services in a clean and professional format.

The website focuses on easy navigation, strong visual presentation, mobile responsiveness, and a simple user experience.

## Key Features

- Modern healthcare-focused website design
- Fully responsive layout for desktop, tablet, and mobile
- Professional homepage section
- Clean and structured page layout
- About page
- Services page
- Vision page
- Testimonials page
- Courses page
- Vacancy page
- Contact page
- WhatsApp appointment button
- Click-to-call button
- Social media link support
- Clean header and footer layout
- Mobile-friendly navigation menu
- Optimized static website structure
- Smooth and user-friendly browsing experience

## Website Pages

### Home
Main landing page with visual branding, service introduction, and appointment call-to-action.

### About
Information section for presenting organization background, purpose, and service approach.

### Services
Dedicated page for listing physiotherapy, rehabilitation, fitness, wellness, and related services.

### Vision
Page for presenting mission, values, long-term goals, and service philosophy.

### Testimonials
Section for displaying client or patient feedback and success stories.

### Courses
Page for showcasing available courses, workshops, or training programs.

### Vacancy
Page for career openings, hiring information, or professional opportunities.

### Contact
Contact-focused page with enquiry and communication options.
